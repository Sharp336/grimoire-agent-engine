# Plan 01-01: Config Cutover and Dual-Mode Guard

<objective>
Register five assembler knobs in the settings schema, wire them through sdk.ts into deriveBudget and transformMessages, and add an explicit fail-closed mode guard so that bounding only runs when contextManager.mode === "assembler". Purpose: Replace hardcoded constants with user-tunable settings and ensure the assembler path is explicitly gated.
Output: Settings registered, consumed in deriveBudget/transformMessages, mode guard enforced, tests updated.
</objective>

</must_haves>

  // Return messages unchanged — no assembler processing

}
