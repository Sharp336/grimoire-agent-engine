# Движок Артели

Визуальный справочник для разбора перед переписыванием.

## Открыть карту

- [[Карта движка.canvas|Устройство движка]] — шесть областей, от исполнения до хранения.
- [[Путь сообщения.canvas|Путь сообщения]] — один успешный ход с вызовом инструмента.

Двойной клик по карточке открывает содержимое. Через контекстное меню карточки можно открыть Markdown отдельной вкладкой. Колесо и перетаскивание помогают перемещаться по Canvas; команда Zoom to fit возвращает всю карту.

## Что здесь достоверно

Названия и ссылки привязаны к исходникам `7d04e380dd0f163c90781aaf4ead32eadb01ccab`. Это небольшой пример организации документации: связи упрощены, задержки и crash recovery не проверялись.

## Для агентов

Начинайте с нужной карточки в папке `Модули`. Проверяйте код до изменения описания. Разделяйте текущую реализацию, предложения и принятые решения. Не выдавайте вопросы в разделе «Для переписывания» за дефекты. Гримуар остаётся источником задач и решений; здесь документация и визуальная навигация.

Сторонних плагинов нет. Canvas — обычный JSON, карточки — Markdown. Оформление лежит в `.obsidian/snippets/artel.css`.
